# Учёт работы — Telegram Mini App

Аналог приложения для учёта заказов и трат мастера/специалиста: **Главная · Заказы · Траты · Статистика · Клиенты · Настройки**.
Работает внутри Telegram, считает прибыль (цена − транспорт) и присылает напоминания о заказах через бота.

## Быстрый старт (SQLite, без зависимостей)
Нужен Node.js ≥ 22.5.
```bash
cp .env.example .env      # впишите BOT_TOKEN
npm start
```
Локально в браузере, без Telegram: `DEV_AUTH=1 npm start` → http://localhost:3000

## Подключение к Telegram
1. Создайте бота в @BotFather, токен → `BOT_TOKEN`.
2. Разместите приложение на любом хостинге с HTTPS (Render, Fly, VPS + Caddy/nginx, Cloudflare Tunnel для теста) и укажите адрес в `WEB_APP_URL`.
3. В @BotFather: `/newapp` (или Menu Button) → тот же адрес. Бот сам поставит кнопку меню «Учёт» и ответит на `/start` кнопкой открытия.
4. Каждый пользователь нажимает `/start` у бота — после этого уведомления приходят ему в личный чат.

### Любой другой бот для уведомлений
В **Настройки → Свой Telegram-бот** пользователь вставляет токен своего бота (проверяется через `getMe`) и, при желании, Chat ID (группа, канал `@name`). Тогда напоминания идут через этот бот; без токена — через бот сервера. Кнопка «Отправить тест» проверяет связку.

## Подключение к любой базе данных
Задаётся одной переменной `DATABASE_URL`, таблицы создаются автоматически:

| СУБД | Значение | Драйвер |
|---|---|---|
| SQLite | `sqlite:./data/app.db` | встроен в Node |
| PostgreSQL | `postgres://user:pass@host:5432/db` (`DB_SSL=1` для облачных) | `npm i pg` |
| MySQL / MariaDB | `mysql://user:pass@host:3306/db` | `npm i mysql2` |

Весь доступ к данным идёт через `db.js` (методы `all/get/run/insert` с плейсхолдерами `?`) — чтобы добавить другую СУБД, достаточно реализовать эти 4 метода и DDL.

## Напоминания
Планировщик раз в минуту ищет невыполненные заказы, до начала которых осталось ≤ выбранного времени («за 30 минут … за 2 дня»), и шлёт сообщение один раз. Перенос заказа сбрасывает напоминание. Время считается в поясе `TZ_NAME`.

## Что где
```
server.js   HTTP, проверка подписи Telegram (initData), REST API
db.js       адаптер SQLite / PostgreSQL / MySQL
bot.js      Telegram Bot API, /start, планировщик напоминаний
public/     интерфейс (чистый JS, без сборки)
```
Данные каждого пользователя изолированы по Telegram ID. `ALLOWED_USERS` ограничивает доступ списком.

## Заметки
- Статистика по умолчанию считает только выполненные заказы (раздел «История»); галочка «Учитывать невыполненные» включает все.
- `DEV_AUTH=1` отключает проверку Telegram — не используйте на публичном сервере.
- Токены своих ботов хранятся в БД открытым текстом — ограничьте доступ к базе и используйте `ALLOWED_USERS`.
